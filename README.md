## Iris Flower Classification using Artificial Neural Network

### Project Overview

This project uses an Artificial Neural Network (ANN) to classify Iris flowers into different species based on their physical measurements.

The Iris dataset contains measurements of:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The ANN model learns patterns from these features and predicts the flower species.

### Objective

The main objective of this project is to build an Artificial Neural Network classification model that can accurately classify Iris flowers into their respective species.

### Dataset

The Iris dataset contains 150 observations and 4 input features.

Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target

- Setosa
- Versicolor
- Virginica

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- Jupyter Notebook

### Project Workflow

1. Import required libraries
2. Load the Iris dataset
3. Explore and understand the dataset
4. Separate features and target
5. Encode the target variable
6. Split the dataset into training and testing sets
7. Scale the input features
8. Build the Artificial Neural Network
9. Train the model
10. Evaluate model performance
11. Make predictions

### Artificial Neural Network

The ANN consists of:

- Input layer
- Hidden layer(s)
- Output layer

The input layer receives the four flower measurements. The hidden layers learn the patterns in the data, and the output layer predicts the Iris species.

### Model Evaluation

The model performance can be evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report
- Training and Validation Accuracy
- Training and Validation Loss


### Conclusion

This project demonstrates how an Artificial Neural Network can be used for a multiclass classification problem. The model learns from Iris flower measurements and predicts the corresponding flower species.

The project provides a basic understanding of ANN model building, preprocessing, training, prediction, and evaluation using Python.
